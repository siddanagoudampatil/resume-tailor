# Keyword alignment (honest)

- Mirror JD phrasing only when factually equivalent to `resume.md`.
- Target ~1–2 aligned terms per bullet; never keyword-stuff footers or hidden repeats.
- Expand acronyms once if JD uses the long form and resume has the skill.
- If JD asks for a skill absent from base resume → **Do not add**, not the tailored resume.
- **Order Skill Categories by Relevance**: Prioritize and re-order the categories in `## Skills` (and/or the items within each category) in the tailored resume so that the technologies most critical to the target job description appear first.
- **Skill-Experience Context / Mapping**: Ensure that if a key skill from the JD is highlighted in the `## Skills` section, it is backed up or reinforced by evidence (matching keywords or contexts) in the bullet points of the `## Experience` or `## Projects` sections.
